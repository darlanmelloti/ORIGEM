# Central de Orientação do Diretor - Projeto ORIGEM

## 1. Visão Geral e Filosofia de Trabalho
Como Diretor de Arte e Enredo, estabeleço este canal centralizado na pasta `/diretor_orientacoes/` do repositório GitHub (`darlanmelloti/ORIGEM`) para auditar, orientar e sincronizar o trabalho simultâneo dos dois desenvolvedores. O padrão de exigência é o fotorrealismo alpino e de Noite Litúrgica ("Liturgical Night"), rejeitando em absoluto geometrias planas, caixas visíveis ou fundos de "outdoor".

## 2. Regras de Ouro para a Equipa
1. **Zero Outdoors**: Todo o horizonte deve ser composto por geometria 3D explorável ou relevos volumétricos reais. O jogador tem de conseguir alcançar fisicamente qualquer montanha visível.
2. **Ciclo Contínuo de Refinamento**: Nenhum desenvolvedor deve parar ou aguardar aprovações burocráticas intermédias. Terminou uma tarefa? Execute o teste, grave o vídeo de 30 segundos, tire o print comparativo e avance para o refinamento seguinte.
3. **Interação Obrigatória a Cada 30 Minutos**: Ambos os desenvolvedores devem atualizar o registo de progresso nesta pasta a cada 30 minutos, submetendo capturas e dúvidas para receber directrizes instantâneas.

## 3. Distribuição de Branches e Pastas no GitHub
- **Repositório Central**: `https://github.com/darlanmelloti/ORIGEM`
- **Desenvolvedor Principal (Início até Take 5)**: Branch `feature/dev1-gameplay-core`
- **Novo Desenvolvedor (Take 5 ao Take 7 e Cubo Orion)**: Branch `feature/dev2-mountain-canyon`
- **Canal de Direção**: Pasta `diretor_orientacoes/` na raiz da branch `main`.

O diretor auditará o código e os artefactos visuais de forma contínua através do repositório, garantindo a coesão absoluta do épico temporal ORIGEM.
