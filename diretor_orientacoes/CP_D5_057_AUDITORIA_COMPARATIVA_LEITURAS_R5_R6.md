# CP-D5-057 — Auditoria comparativa das leituras R5/R6

## Resultado

A comparação das leituras de Elias em R5 e R6 confirmou que ambas respeitam os mesmos contratos de câmara, grounding, trajecto e isolamento, com composições vegetais distintas e sem parede de árvores.

| Critério | R5 Majestic | R6 Ruínas |
|---|---:|---:|
| Vegetação | 5 elementos | 3 elementos |
| Folga | 5,45 m | 6,05 m |
| Grounding do marco | true | true |
| Câmara de Elias activa | false | false |
| Ciclos de trajecto | 2 | 2 |
| Parede de árvores | false | false |
| Lajes de cais | 0 | 0 |
| Módulos de produção alterados | false | false |
| Luzes do harness | 1 direccional | 1 direccional |

O parser Compatibility passou sem erros e a evidência de runtime dos dois previews confirma X/Z canónico, câmara QA proprietária e ausência de integração regional. A composição R6 mantém leitura arqueológica da baliza sem repetir a linguagem rejeitada de cais.

O inventário está em `CP-D5-057_R5_R6_READ_COMPARISON_AUDIT.log`.
