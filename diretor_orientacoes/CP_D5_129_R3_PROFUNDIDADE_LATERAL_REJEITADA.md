# CP-D5-129 — Profundidade Lateral R3: Rejeitada Visualmente

## Decisão

A variante QA do corredor R3 executou com êxito técnico: parser Godot 4.7.1 sem erros, 36 segundos de sessão, duas travessias completas, rota aberta, destino R4 confirmado e seis elementos laterais fora do corredor. Contudo, a captura revelou uma leitura de protótipo: terreno plano, balizas técnicas demasiado dominantes, contraste insuficiente e activos sem integração material convincente.

| Critério | Resultado |
|---|---|
| Âncora R3 X/Z | `(-16,741; 48,00)` preservada |
| Corredor R3→R4 | Aberto, sem arco estrutural |
| Luzes dinâmicas novas | 0 |
| Gameplay QA | 36 segundos; 2 ciclos aprovados |
| Aceitação visual | `REJECTED_VISUAL` |

A alteração não é promovida nem usada como base de produção. Os activos laterais desta variante são revertidos para evitar repetir uma linguagem de plano de ensaio. O próximo refinamento deve actuar sobre uma hipótese visual que já tenha solo, relevo e materiais de produção reais, em vez de ampliar uma cena de QA plana.
